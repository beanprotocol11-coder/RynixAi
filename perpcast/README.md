# Perpcast

Cast, chat and trade perps in one place — live at **https://perpcast.app** · user docs at **https://perpcast.app/docs**.

A cast-style social network with a Hyperliquid-powered perp terminal, Pons token launches and the Perpcast Mascots NFT collection on Robinhood Chain. No third-party social protocol: identity is your email or wallet, and the social graph lives in Perpcast's own D1 database.

## Features

- **Social** — casts (text, up to 4 images, `$TICKER` price chips, `/channels`), replies, quotes, likes, recasts, follows, bookmarks, profiles with avatar/banner upload, notifications, search (People / Casts / Memes), keycap category filters.
- **DMs** — end-to-end encrypted in the browser (device-local key pair; server stores ciphertext only).
- **Trade** — Crypto, Memes, Stocks and RWAs from Hyperliquid (main dex + `xyz` builder dex): live prices, candles, order book, trades; market/limit orders, leverage, TP/SL, liquidation, fills, portfolio. **Paper trading only** — desk starts at $0, paper USDC is added manually.
- **Launch** — deploy a meme token via the Pons V2 factory on Robinhood Chain from the user's wallet (logo upload, economics preview, launch fee).
- **NFTs** — Perpcast Mascots: 30 pixel-art ERC-721s, voucher-gated mint (server-signed per wallet, 1 per wallet, account-age + IP limits). v1 (`0x4a77…23ab`) is sold out and kept as Genesis; v2 is `0xC3750d2dB03BCb2929DD7268C400510a45437161`.
- **Wallet** — EIP-6963 discovery, mobile deep links, WalletConnect; live Balance chip (Hyperliquid + Robinhood Chain + Arbitrum); automatic Robinhood Chain add/switch; layered RPC fallback (official → dRPC → `/api/rpc` relay).
- **Sign in** — email OTP (Resend, `login@perpcast.app`) or wallet signature. Wallet addresses are never shown publicly.

## Develop

```bash
npm install
npm run dev      # http://localhost:5173 (local mode: API served from localStorage)
npm run build    # tsc -b && vite build → dist/
npm run lint     # oxlint
npx wrangler pages dev dist   # with Pages Functions + D1 (needs wrangler login)
```

## Backend

`functions/` — Cloudflare Pages Functions (`/api/*`) on D1 (`migrations/*.sql`, apply with `wrangler d1 migrations apply perpcast --remote`):

| Area | Routes |
| --- | --- |
| Auth | wallet nonce + signature verify, email OTP request/verify, session |
| Social | users, casts, reactions, follows, activity, search |
| DMs | public keys, encrypted conversations |
| Uploads | `/api/upload` (avatars, banners, token logos, cast images) |
| Chain | `/api/rpc` same-origin RPC relay for Robinhood Chain |
| NFTs | `/api/mascots/voucher` — signs mint vouchers with `MASCOTS_SIGNER_KEY` |

Secrets on the Pages project: `RESEND_API_KEY`, `MASCOTS_SIGNER_KEY`. Binding: D1 as `DB`.

The client probes `/api/health` on boot; if the API is unreachable it falls back to **local** mode (`localStorage`, `perpcast:` prefix).

## Contracts

- `contracts/PerpcastMascots.sol` — v1 (open mint, `MAX_SUPPLY = 30`, sold out).
- `contracts/PerpcastMascotsV2.sol` — v2: `mint(deadline, v, r, s)` verifies an EIP-191 signature over `(contract, chainId, wallet, deadline)` from the server signer; `minted[wallet]` enforces one per wallet; `reserve()` (owner, only while supply is 0).
- Metadata + 512px PNGs generated by `scripts/build-mascots.mjs` into `public/mascots/`.

## Deploy

Cloudflare Pages: root `perpcast`, build `npm run build`, output `dist`. `public/_redirects` handles SPA routing, `public/_headers` disables HTML caching so new builds load immediately. `.github/workflows/deploy-perpcast.yml` deploys on push to `main`; manual: `npx wrangler pages deploy dist --project-name perpcast --branch main`.
